# 💱 Currency App

## API

Для получения курсов валют и исторических данных используется
**[Frankfurter API](https://api.frankfurter.dev/v2)**.

- Не требует API-ключа.
- Предоставляет данные об обменных курсах валют.

Документация: [api.frankfurter.dev](https://api.frankfurter.dev/)

---

## 🚀 Запуск проекта

### Требования

- Node.js
- npm

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm start
```

Приложение будет доступно по адресу
[http://localhost:3000](http://localhost:3000).
